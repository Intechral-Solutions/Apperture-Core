# AUD-1.4 coverage matrix

Status: working record of the AUD-1.4 closure (slice 8). Not a contract. The contract is the [AUD-1.0 design gate](aud1-design-gate.md) section 22 and the [implementation record](aud1-4-configuration-lifecycle-record.md) sections 5 and 6.

The matrix connects each active audit action that AUD-1.4 introduced or converted to its writer, its typed producer, its catalog classes and the tests that evidence it. It was drawn by reading the tests at `aud-1.4-slice-8-closure` after the first work package of slice 8, then updated by the evidence work package (section 6.0). It says what each test asserts, not that it passed; the passes are in the record (section 19). Test names are kept and line numbers are not, because they go stale.

**Reading the markers.** A cell that says **GAP**, or a row that lists a gap id (G1 and so on), shows what was open when the matrix was drawn. Section 6.0 gives the state of every gap at closure. The retired actions (`governance.break_glass.admin_operation`, `execution.operation_item.bulk_retry.requested`, `execution.operation_item.bulk_retry.completed`, `recovery.blocked_work.retry_dispatched`) are marked `Retired` in the catalog and are not in the matrix.

# Incident Postmortem Prompt

Use this prompt when conducting an incident postmortem.

## Sections

1. **Summary** — What happened, impact, duration
2. **Timeline** — Key events in order
3. **Root cause** — Primary cause; contributing factors
4. **Detection** — How the incident was detected
5. **Resolution** — How it was fixed
6. **Follow-ups** — Action items to prevent recurrence
7. **Lessons learned** — What we learned

## Format

Store postmortems locally in `archives/YYYY-MM/` (gitignored) or a designated incidents folder. Use markdown. Link to runbooks or ADRs if relevant.

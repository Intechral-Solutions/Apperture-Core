# Module Scaffold Prompt

Use this prompt when scaffolding a new module.

## Context

- Module SDK: [.ai/playbooks/module-sdk.md](../playbooks/module-sdk.md)
- Project map: [.ai/playbooks/project-map.md](../playbooks/project-map.md)

## Request

Scaffold a new Apperture module with:

1. Module project (workflow definitions, step implementations)
2. Contracts project (parameter schemas, DTOs)
3. Optional UI project (Blazor components)

Follow the structure of Sample.HelloWorld. Ensure manifest metadata, workflow registration, and step implementations align with the SDK.

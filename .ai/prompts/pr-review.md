# PR Review Prompt

Use this prompt when requesting a code/PR review.

## Context

- Project: Apperture Core
- Principles: [.ai/playbooks/principles.md](../playbooks/principles.md)
- Anti-patterns: [.ai/playbooks/anti-patterns.md](../playbooks/anti-patterns.md)

## Request

Review the PR for:

1. Consistency with project architecture and dependency rules
2. No violation of anti-patterns (message-based orchestration, scheduler executing steps, etc.)
3. Appropriate test coverage
4. Documentation updates if needed
